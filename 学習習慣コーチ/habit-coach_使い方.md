# `/habit-coach` スキル 使い方ガイド

## 概要

`/habit-coach` は子どもが自ら机に向かう状態を作るための学習習慣コーチを起動するスラッシュコマンドです。
やる気・継続・集中・習慣化の4つの問題に対応しています。

---

## 基本的な呼び出し方

```
/habit-coach [今の状況]
```

状況を省略すると「今の学習の様子を教えてください」と確認してから始めます。

---

## 使い方 パターン別

### パターン A：習慣リセットプラン（机に向かえないとき）

**入力例**
```
/habit-coach 最近全く机に向かえない。帰ってきたら動画を見てそのまま寝てしまう
/habit-coach テストが終わってから気が抜けて勉強できていない
/habit-coach やる気がゼロ。何をどうしていいかわからない状態
```

**出力内容**
- やる気を奪っている原因の特定（外部・内部要因）
- 今日だけ取り組める超具体的な小アクション（5〜10分以内）
- 動画など既存習慣にくっつけた週間スケジュール設計
- 親の声掛け例（言ってよいこと・いけないこと）

---

### パターン B：継続設計プラン（三日坊主になるとき）

**入力例**
```
/habit-coach 始めるけど3日で崩れる。どうしたら続くか
/habit-coach 月曜は頑張るけど木曜になると崩れてしまう
/habit-coach 計画を立てても守れない
```

**出力内容**
- 継続を妨げているパターンの分析（目標が高すぎる・仕組みがないなど）
- 目標を下げて続けられる設計への修正
- 記録の見える化方法（カレンダー・シールなど）
- 崩れたときのリカバリールール
- 「1週間の実験」として心理的ハードルを下げた計画

---

### パターン C：集中環境プラン（集中できないとき）

**入力例**
```
/habit-coach 机に座っても5分で気が散る
/habit-coach スマホが気になって勉強に集中できない
/habit-coach 夕食後は眠くて集中できない。いつやればいいか
```

**出力内容**
- 集中を妨げている原因の特定（環境・時間帯・疲れなど）
- 最適な勉強時間帯の提案
- 机・スマホ・照明などの物理環境の整備案
- 集中の単位時間設計（何分やって何分休むか）
- 今日すぐ変えられる環境変化1つ

---

### パターン D：習慣化フルプラン（全体を整えたいとき）

**入力例**
```
/habit-coach 全体的な生活リズムを見直したい
/habit-coach 放課後から就寝までのルーティンを設計してほしい
/habit-coach 塾の宿題と自学自習のバランスが取れていない
```

**出力内容**
- 現在の1日の習慣マップ（放課後・夕食後・就寝前・週末）
- 無理なく続けられる理想の1日ルーティン設計
- 動画の「制度化」ルール（敵にせず儀式として使う）
- 今週だけ試す最小スタートアクション
- 2週間後の成功イメージ
- 親が毎日・週1回やること、やめること

---

## このスキルが大切にしていること

### 動画は「敵」にしない

今の娘さんは「動画を見てからでないと勉強を始められない」状態です。
このスキルでは動画を取り上げるのではなく、**「動画→勉強」の流れを仕組みにする**ことを前提としています。

### 最初の目標は「5分だけ」

やる気がない状態に長時間勉強の計画を立てても続きません。
「5分だけやってみる」レベルから始め、成功体験を積み重ねる設計をします。

### 親は管理者ではなくサポーター

「なぜやらないの」「もっとやりなさい」という声掛けの提案はしません。
子どもが自分で動き出せる環境と仕組みを作ることに集中します。

---

## 状況を詳しく伝えるとより精度が上がる

```
/habit-coach [状況を教えてください]

例：
・今の学習時間はどのくらいか
・動画はいつ・何時間くらい見ているか
・崩れるのはどのタイミングか
・塾の宿題はこなせているか
・本人のやる気・気持ちはどんな感じか
```
