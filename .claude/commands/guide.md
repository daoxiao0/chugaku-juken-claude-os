## 入力された絞り込み条件（任意）

$ARGUMENTS

条件が空の場合は、以下の内容を全部出力してください。
条件がある場合（例: 「志望校戦略」「habit-coach」「メンタル」など）は、該当する項目を詳しく、それ以外は見出しだけ簡潔に出力してください。

## 出力する内容

### 0. まず迷ったら

`/parent-strategy` に今週の状況（模試結果・子どもの様子・気になっていることなど）を入力してください。全体を統合して「今週やること」を出す司令塔です。個別の悩みが具体化してきたら、以下の専門コマンド・フォルダに移ってください。

---

### 1. スラッシュコマンド一覧（今すぐ使える4つ）

#### `/parent-strategy` — 保護者戦略室（司令塔）
- **呼び出し方**: `/parent-strategy [今週の状況]`
- **入力例**:
  - `/parent-strategy 今週の模試で理科が43点だった。本人は落ち込んでいる`
  - `/parent-strategy 特に問題はないが、今週やるべきことを整理してほしい`
- **出てくるもの**: 現状分析（学習・メンタル・家庭環境・受験戦略）→ 今週の最重要課題 → 親子それぞれの行動計画 → 注意事項 → 他フォルダへの引き継ぎ指示

#### `/school-strategy` — 志望校戦略室
- **呼び出し方**: `/school-strategy [依頼内容]`
- **入力例**:
  - `/school-strategy 〇〇学園を調べてください`
  - `/school-strategy 共学校3校を比較して：A校・B校・C校`
  - `/school-strategy 出願校リストを作りたい`
- **出てくるもの**: 学校分析レポート／比較表／出願戦略プラン（チャレンジ・実力・安全校のバランス提案込み）
- **詳しい使い方**: `志望校戦略/school-strategy_使い方.md`

#### `/habit-coach` — 学習習慣コーチ
- **呼び出し方**: `/habit-coach [今の状況]`
- **入力例**:
  - `/habit-coach 最近全く机に向かえない`
  - `/habit-coach 始めるけど3日で崩れる`
  - `/habit-coach 全体的な生活リズムを見直したい`
- **出てくるもの**: 状況に応じて「習慣リセット」「継続設計」「集中環境」「習慣化フルプラン」のいずれかの形式で、超具体的な小アクションと親の関わり方を提案
- **詳しい使い方**: `学習習慣コーチ/habit-coach_使い方.md`

#### `/exam-schedule` — 受験スケジュール管理室
- **呼び出し方**: `/exam-schedule [確認したいこと]`
- **入力例**:
  - `/exam-schedule 今月の予定を整理して`
  - `/exam-schedule 出願の締め切りが近い学校はある？`
- **出てくるもの**: 今月・今週の予定、重要期限、忘れやすい事項、次にやること

### 2. スラッシュコマンドがまだ無いフォルダ（会話に直接読み込ませて使う）

以下の4フォルダはまだ専用コマンド化されていません。使うときは、対象フォルダの `CLAUDE.md` の内容を会話にそのまま貼り付ける（または「学習コーチのCLAUDE.mdを読んで、この問題を解いて」のように指示する）と、同じ役割で応答します。

| フォルダ | こういうときに使う | 入力例 |
|---------|-----------------|--------|
| `学習コーチ/` | テスト・宿題の問題を解かせたいとき | 「この算数の問題を、学習コーチとして教えて：〇〇」 |
| `模試分析/` | 模試結果が届いたとき | 「模試分析のCLAUDE.mdに沿って、この結果を分析して：〇〇」 |
| `過去問分析/` | 志望校の過去問対策をしたいとき | 「過去問分析として、〇〇中の算数の出題傾向を教えて」 |
| `メンタルサポート/` | 子どもがメンタル的に落ち込んでいるとき | 「メンタルサポートとして、こういう発言をしていた場合の声掛けを考えて：〇〇」 |

### 3. 全体のフォルダ構成

```
中学受験プロジェクト/
├── CLAUDE.md                ← 全体共通コンテキスト（受験生プロフィール・最重要原則）
├── 保護者戦略室/            ← 司令塔。全フォルダを統合し週次戦略を立案 → /parent-strategy
├── 学習コーチ/              ← 日々の学習指導
├── 模試分析/                ← 模試結果から課題を抽出
├── 過去問分析/              ← 志望校の出題傾向分析
├── 志望校戦略/              ← 出願校の選定・比較 → /school-strategy
├── 学習習慣コーチ/          ← やる気・継続・習慣化支援 → /habit-coach
├── メンタルサポート/        ← 心理状態管理・自己肯定感サポート
└── 受験スケジュール管理/    ← 日程の一元管理 → /exam-schedule
```

各フォルダの `参考資料/` に元データ（模試結果・学校資料など）を、`成果物/` に出力結果を保存する運用です。どちらも `.gitignore` で除外されるため、Gitでバージョン管理していても個人データが外部に漏れることはありません。

---

### 4. カスタマイズしたいとき

- 受験生のプロフィール（学年・受験日・偏差値など）は、ルートの `CLAUDE.md` と各フォルダの `CLAUDE.md` にある `[学年・性別を記入]` のようなプレースホルダーを書き換えてください
- 新しい専門分野を追加したい場合は、既存フォルダをコピーして `CLAUDE.md` を書き換え、ルートの `CLAUDE.md` の「フォルダ構成と役割」表に追記してください
