# 中学受験プロジェクト for Claude Code

**Claude Code で中学受験の「保護者の伴走」をチーム戦にするテンプレート。**
学習指導・模試分析・志望校選び・メンタルケア・スケジュール管理…と役割ごとに専門化されたAIエージェントを8つのフォルダに分けて配置し、司令塔となる「保護者戦略室」が全体を統合して週次の行動計画に落とし込みます。

---

## これは何のためのテンプレートか

中学受験の伴走は、実は複数の異なる専門性が同時に必要になる仕事です。

- 算数・国語・理科・社会の学習指導
- 模試結果の分析と弱点抽出
- 志望校の比較・出願戦略
- 子どものやる気・習慣形成
- メンタルの浮き沈みへのケア
- 説明会・出願・受験当日のスケジュール管理

これを1つの雑多な会話でAIに丸投げすると、話がすぐ混ざって精度が落ちます。このテンプレートは、**役割ごとにフォルダとAIの人格（CLAUDE.md）を分離**し、それぞれが専門特化した出力を返す構成にすることで、この問題を解決します。

## 特徴・強み

- **役割特化型のマルチエージェント構成**: 8つの専門フォルダ（学習コーチ／模試分析／過去問分析／志望校戦略／学習習慣コーチ／メンタルサポート／受験スケジュール管理／保護者戦略室）が、それぞれ独立した人格・出力フォーマット・禁止事項を持つ
- **司令塔（保護者戦略室）による統合**: 各フォルダの知見を毎週まとめ、「親がやること」「子どもがやること」を具体的なタスクとして出力する`/parent-strategy`が中心導線
- **「親子関係 > 成績」という原則を全フォルダに徹底**: どのエージェントも「結果より自己肯定感」「比較しない・説教しない」というルールを最優先で守るよう設計されている
- **すぐ使えるスラッシュコマンド**: `/parent-strategy` `/school-strategy` `/habit-coach` `/exam-schedule` の4つはコマンド一発で専門エージェントを起動できる
- **プライバシー設計込み**: 実際の成績・志望校・家庭の状況などを書き込む`成果物/`・`参考資料/`フォルダは`.gitignore`で自動的に除外される設計になっており、**このテンプレートをそのままForkしても個人情報が漏れる心配がない**
- **Claude Code専用ではあるが、他のAIツールでも使い回せる**: 中身はただのMarkdown（役割定義＋出力フォーマット）なので、ChatGPT・Geminiなど他のAIに使う場合はその内容をカスタム指示欄に貼り付けるだけで同じ動きを再現できる

## フォルダ構成

```
中学受験プロジェクト/
├── CLAUDE.md                ← 全体共通コンテキスト（受験生プロフィール・最重要原則）
├── 保護者戦略室/            ← 司令塔。全フォルダを統合し週次戦略を立案
├── 学習コーチ/              ← 日々の学習指導（算数・国語・理科・社会）
├── 模試分析/                ← 模試結果から課題を抽出・優先順位付け
├── 過去問分析/              ← 志望校の出題傾向分析・得点戦略立案
├── 志望校戦略/              ← 出願校の選定・比較・受験校決定支援
├── 学習習慣コーチ/          ← 自学自習の習慣化・やる気・継続支援
├── メンタルサポート/        ← 子どもの心理状態管理・自己肯定感サポート
└── 受験スケジュール管理/    ← 模試・説明会・出願・受験日程の一元管理
```

各フォルダは共通して `参考資料/`（教材・模試結果・学校資料などのインプット）と `成果物/`（分析レポート・行動計画などのアウトプット）を持ちます。この2つは`.gitignore`で除外されるため、実際に使い込んでも個人データがリポジトリに残りません。

## 使い方（クイックスタート）

1. このリポジトリをFork、またはダウンロードして自分用のフォルダにする
2. [Claude Code](https://claude.com/claude-code) をインストールし、このフォルダで起動する
3. `CLAUDE.md` と各フォルダの `CLAUDE.md` を開き、`[学年・性別を記入]` のようなプレースホルダーをあなたの家庭の状況に書き換える
4. 迷ったらまず `/parent-strategy` を実行し、今週の状況（模試結果・子どもの様子など）を入力する
5. 出てきた行動計画に沿って、必要な専門フォルダ（志望校戦略・学習習慣コーチなど）を個別に呼び出していく

## スラッシュコマンド一覧

| コマンド | 起動する専門室 | できること |
|---------|---------------|-----------|
| `/parent-strategy` | 保護者戦略室 | 今週の状況を入力すると、親子それぞれの週次行動計画を出力する司令塔 |
| `/school-strategy` | 志望校戦略室 | 学校の個別分析・複数校比較・出願校リスト作成 |
| `/habit-coach` | 学習習慣コーチ | やる気低下・三日坊主・集中力不足への習慣化プラン提案 |
| `/exam-schedule` | 受験スケジュール管理室 | 模試・説明会・出願・受験本番・入学手続きの日程管理 |

スラッシュコマンドがまだ無い4フォルダ（学習コーチ・模試分析・過去問分析・メンタルサポート）は、そのフォルダの `CLAUDE.md` の内容を会話に読み込ませることで同様に使えます。

## カスタマイズ方法

- 各フォルダの `CLAUDE.md` は「人格・出力フォーマット・禁止事項」の3点セットで構成されています。文体や優先順位を変えたい場合はこのファイルを直接編集してください
- 新しい専門分野（例: 英語対策、帰国子女枠対応など）を追加したい場合は、既存フォルダをコピーして `CLAUDE.md` を書き換え、ルートの `CLAUDE.md` の「フォルダ構成と役割」表に追記してください
- 新しいスラッシュコマンドを追加したい場合は `.claude/commands/` に既存コマンドを参考にした `.md` ファイルを追加してください

## 他のAIツールで使いたい場合

各フォルダの `CLAUDE.md` は、Claude Codeが自動で読み込む前提のファイルですが、中身はただの役割定義テキストです。

- **ChatGPT / Gemini など**: 使いたいフォルダの `CLAUDE.md` の内容を丸ごとコピーし、カスタム指示（Custom Instructions）やシステムプロンプトとして貼り付ける
- **Codex CLI / Cursor など `AGENTS.md` 規約に対応したツール**: `CLAUDE.md` をコピーして `AGENTS.md` という名前で保存すれば、そのまま同じ内容を自動読み込みできる

## 注意事項

- 本リポジトリは、四谷大塚・日能研・SAPIXなど特定の塾・模試運営会社とは一切関係のない、個人が作成したプロンプトテンプレートです
- 塾の教材・模試の偏差値表など第三者の著作物は一切含まれていません（`.gitignore`で個人の参考資料フォルダごと除外する設計になっています）
- あくまで保護者の意思決定を助ける補助ツールであり、最終的な学習方針・受験校の決定は必ず保護者・お子さん自身で判断してください
