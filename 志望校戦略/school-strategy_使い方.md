# `/school-strategy` スキル 使い方ガイド

## 概要

`/school-strategy` は志望校選定の専門コンサルタントを起動するスラッシュコマンドです。
学校の個別分析・複数校の比較・出願校リストの作成の3つの用途に対応しています。

---

## 基本的な呼び出し方

Claude Code のチャットで以下のように入力します。

```
/school-strategy [依頼内容]
```

依頼内容を省略すると、どの学校を調べるか・何を相談したいかを確認してから始めます。

---

## 使い方 パターン別

### パターン A：特定の学校を詳しく調べたいとき

**入力例**
```
/school-strategy 女子学院を調べてください
/school-strategy 豊島岡女子学園の情報を教えて
/school-strategy 吉祥女子は娘に合っていますか？
```

**出力内容**
- 基本情報（所在地・偏差値・学校形態）
- 校風・教育方針・大学進学実績・部活
- 現在の偏差値からの合格可能性評価
- チャレンジ校 / 実力校 / 安全校の区分判定
- 推薦度（★5段階）
- 次にやること（説明会・文化祭など）

---

### パターン B：複数の学校を比べたいとき

**入力例**
```
/school-strategy 豊島岡と吉祥女子を比較して
/school-strategy 共学校3校を比べたい：渋渋・広尾学園・三田国際
/school-strategy 安全校の候補として考えている3校を比較してほしい
```

**出力内容**
- 比較表（偏差値・校風・通学・推薦度を一覧）
- 各校の強み・弱み・娘との相性
- おすすめ順位と理由

---

### パターン C：出願校リストを作りたいとき

**入力例**
```
/school-strategy 出願校リストを作りたい
/school-strategy 2月の受験スケジュールを組んでほしい
/school-strategy チャレンジ・実力・安全校を組み合わせた戦略を立てて
```

**出力内容**
- 推奨出願校リスト（区分ごとに整理）
- 2月1日〜5日の受験日程の組み方
- 1月受験（地方校）の活用方法
- 今後のスケジュール（説明会・出願期限など）
- 保護者戦略室への引き継ぎ事項

---

## 活用のコツ

### 情報を一緒に渡すと精度が上がる

学校パンフレットや説明会メモがある場合は、テキストを貼り付けて渡すと分析の精度が上がります。

```
/school-strategy 以下の情報をもとに〇〇学園を分析してください

[説明会で聞いた内容や学校HPの情報をここに貼る]
```

### 娘の希望を伝える

```
/school-strategy 娘が「制服がかわいい学校がいい」「理系に強い学校がいい」と言っています。
この条件で実力校を3校ピックアップしてください。
```

### 複数回に分けて絞り込む

1回目で候補を広く出してもらい、2回目で絞り込む使い方が効果的です。

```
1回目: /school-strategy 偏差値50前後の女子校を5校リストアップして
2回目: /school-strategy このうち通学1時間以内の学校を詳しく分析して
```

毎回説明しなくても以下の情報がスキル内に組み込まれています。

| 項目 | 内容 |
|------|------|
| 学年 | [学年・性別を記入] |
| 受験日 | [受験日を記入] |
| 通塾 | [通塾先を記入] |
| 現在の偏差値（更新時点） | [4科平均を記入] |
| 国語 | [記入] |
| 算数 | [記入] |
| 社会 | [記入] |
| 理科 | [記入] |

## 成果物の保存場所

このスキルで作成した分析レポート・比較表・出願校リストは以下に保存してください。

```
志望校戦略/
├── 参考資料/   ← 学校パンフレット・説明会メモ・偏差値表
└── 成果物/     ← 学校分析レポート・比較表・出願校リスト
```
